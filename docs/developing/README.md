# Developing SquadDash

This section is for developers working on SquadDash itself. It covers the tools and workflows that are only available in development mode: the **Developer menu**, the **Trace Log**, and the **Guided Tour** authoring system.

## What's in this section

| Page | Description |
|---|---|
| [Developer Menu](developer-menu.md) | The menu that appears in dev mode, with diagnostics, simulation tools, and tour authoring |
| [Trace Log](trace-log.md) | A floating window that streams internal application events in real time |
| [Creating Guided Tours](guided-tours.md) | How to build step-by-step interactive walkthroughs for users |

## Enabling Developer Mode

The Developer menu appears automatically when the current workspace folder contains a `squad-dash.slnx` file — that is, when SquadDash is opened against its own source repository. No separate setting is required.
